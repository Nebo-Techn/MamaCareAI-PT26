# MamaCare AI

MamaCare AI is a Swahili conversational AI project focused on providing
natural, accessible, and trustworthy maternal and newborn health information.

The system is built around reputable health sources, structured knowledge,
retrieval-augmented generation (RAG), language technologies, safety
mechanisms, and systematic evaluation.

This repository contains the project's data, ingestion pipelines, knowledge
processing, RAG, LLM, safety, evaluation, API, application, and documentation
workflows.

> MamaCare AI is an educational and technical project. It does not replace
> qualified medical professionals or emergency medical care.
