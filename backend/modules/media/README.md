# Media — OUT OF SCOPE for the 8-week MVP

This folder is reserved for future work: voice-note transcription and image
handling in the bot. It is **not** part of the committed 8-week deliverable.

Why it's parked, not deleted: given a free-tier-only LLM budget and a fixed
8-week window, the realistic and honest commitment is a **text-only Swahili
chat product** delivered well, not a multi-modal product delivered badly.
Voice/image support is real future scope for MamaCare AI, kept visible here
so it isn't silently forgotten — but nobody should start building in this
folder before the text MVP (ingestion → knowledge → RAG → safety → bot) is
working end-to-end and evaluated.

**Owner track:** none assigned — stretch goal only, pick up only if the core
product is demo-ready ahead of schedule.
