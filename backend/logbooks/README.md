# Logbooks

Each trainee keeps a weekly logbook here — required for Nebo's internal
tracking and for your university's practical training report. One file per
person per week: `logbooks/<name>/week-01.md`, `week-02.md`, etc. Copy
`TEMPLATE.md` to start each week's file.

Fill in a few lines at the end of each working day — it takes two minutes and
is far more accurate than trying to reconstruct a week from memory on Friday
afternoon. Submit (open a PR adding the week's file, or push directly to your
own logbook folder per whatever the team agrees in `docs/COLLABORATION.md`)
by end of day Friday each week for program-lead sign-off.

This is also just useful evidence: when you write your CV or talk about this
placement in an interview, this is the record of what you actually did, week
by week, in your own words.
